# Better Education

Школьное пространство на русском языке с независимыми интерфейсом и API.

## Структура

- `src/App.jsx` — оболочка приложения, главная, чат и API-клиент.
- `src/Pages.jsx` — учебные разделы и панель школы.
- `src/styles.css` — дизайн и адаптация к мобильным экранам.
- `assets/beka.png` — сменный маскот; также можно указать HTTPS URL в настройках разработчика.
- `server/api.js` — проверка ролей, квизы, оценки, BEcoins, серии и чат.
- `server/data.js` — подготовленный учебный контент и отдельный демонстрационный профиль.
- `db/schema.js`, `drizzle/` — схема D1 и миграции.
- `server/api.test.js` — проверки полномочий и начислений.

## Запуск и сборка

Node.js 22+. `npm ci`, `npm test`, `npm run build`.
Деплойный артефакт: `dist/server/index.js`; биндинг D1: `DB`.
Применять миграции из `drizzle/` перед первым запуском API с базой данных.

## Доступ

Входом управляет хостинг Sites через ChatGPT. API использует проверенные заголовки платформы `oai-authenticated-user-id/email`. При переносе на другой хостинг эти заголовки должны устанавливать только доверенные серверные middleware после проверки сессии; нельзя доверять заголовкам из интернета. Публикация сайта сама по себе не приглашает школу: внешний доступ настраивается отдельно.

Новые аккаунты становятся учениками без назначенного класса. Переменная `BOOTSTRAP_DEVELOPER_EMAIL` выдаёт разработчику доступ только для совпадающей подтверждённой почты. Разработчик назначает директору роль; директор управляет учителями, завучами и учениками своей школы. Учитель видит назначенный ему класс. Один учитель — один класс в этой версии. Журнал важных изменений находится в `audit_log`.

Личный кабинет сохраняется в D1. Демо-профиль хранится отдельно в браузере, содержит примеры и позволяет просмотреть разные роли. Переключатель демо не меняет реальные права. Для добавления пользователей они сначала должны войти на сайт; затем разработчик/директор назначает им роль и класс.

## Правила

Оценка 5: +30 BEcoins, 4: +15; квиз от 60%: +20 однократно; материал: +5 однократно; спринт от 6 верных ответов: +10 один раз в день. Повторные запросы не создают вторую награду. Рейтинг основан на звёздах. Серия растёт после завершённого учебного действия в календарный день Asia/Qyzylorda. 10 дней: +50, 50: +250, 100: +500, 200: +1000, далее каждые 100 дней — +500 BEcoins. Награда за каждый порог выдаётся один раз за всё время.

Курсы пока отмечены «Скоро», средства не списываются. Для запуска продаж потребуется добавить контент курсов и выдачу доступа после покупки. Не следует включать `live`, пока оба действия не реализованы.

## Beka

Чат открывается по клику на маскота. Без внешнего сервиса работает честно обозначенный режим готовых учебных объяснений. Для настоящего ИИ предусмотрено прямое серверное подключение к OpenAI через `OPENAI_API_KEY`; плагин для работы сайта не требуется. Ключ хранится в секретах хостинга, никогда в исходниках и браузере. Дневной лимит: 50 запросов на пользователя. Режим ИИ не включён по умолчанию.

Интерфейс можно заменить без изменения правил: сохранить контракт `/api/state`, `/api/quiz/:id`, `/api/grades`, `/api/achievements`, `/api/materials`, `/api/schedule`, `/api/users/:id`, `/api/chat`.
